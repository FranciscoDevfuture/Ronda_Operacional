# Checklist Digital para Rondas Sustentáveis

Sistema web em HTML puro para registro de rondas corporativas sem uso de papel.

## 🎯 Problema
Operações industriais ainda dependem de checklists impressos. Resultado: desperdício de papel, perda de registros e dificuldade pra auditoria entre turnos.

## 💡 Solução
Aplicação web responsiva que roda 100% no navegador de qualquer Android ou Tablet. O agente acessa, marca os itens da ronda e compartilha o relatório direto no grupo do turno.

## ✨ Funcionalidades
- [ ] Interface mobile-first, funciona offline
- [ ] Checklist customizável por empresa
- [ ] Geração de relatório pronto pra compartilhar 
- [ ] Foco em tablet dedicado - zero distração

## 🛠️ Tecnologias
HTML5, CSS3, JavaScript - Sem frameworks. Leve e compatível com qualquer dispositivo.

## 🚀 Como usar
1. Clone o repositório
2. Abra `index.html` no navegador do tablet
3. Adapte os itens do checklist no arquivo `checklist.json`

## 📊 Impacto
Projeto autoral desenvolvido durante curso de ADS. Foco: sustentabilidade + eficiência operacional.
